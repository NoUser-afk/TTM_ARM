# Изменения ARM для переноса в прод

Дата: 02.07.2026

Ветка релиза: `release/selected-arm-changes`

## Суть доработки

Доработан серийный учет для документа `ОтгрузкаТоваровСХранения`.

Теперь отгрузка с хранения:

- может быть записана в регистре серий как документ реализации;
- при проведении привязывает серии к себе и ставит признак `Реализовано`;
- при отмене проведения или пометке на удаление предупреждает пользователя, что связанные серии будут отвязаны.

## Изменение регистра

В регистре накопления `ТТМ_УчетСерийныхНомеровПродукции` у измерения `ДокументРеализации` добавлен тип:

```text
ДокументСсылка.ОтгрузкаТоваровСХранения
```

Было:

```text
ДокументРеализации -> РеализацияТоваровУслуг
```

Стало:

```text
ДокументРеализации -> ОтгрузкаТоваровСХранения, РеализацияТоваровУслуг
```

## Изменение записи серий

В общем модуле `ТТМ_Подписки` изменена обработка `ОтгрузкаТоваровСХранения`.

### Добавлено

При установке или снятии признака реализации теперь определяется документ реализации для серий:

```bsl
//++ Панин + Codex 02.07.2026
ДокументРеализации = ?(ЗначениеРеализовано, Источник.Ссылка, Документы.ОтгрузкаТоваровСХранения.ПустаяСсылка());
//-- Панин + Codex 02.07.2026
```

В найденных строках регистра теперь обновляется ссылка на документ реализации:

```bsl
//++ Панин + Codex 02.07.2026
СтрНЗ.ДокументРеализации = ДокументРеализации;
//-- Панин + Codex 02.07.2026
```

### Было

При записи расхода серии документ реализации очищался, а серия не считалась реализованной:

```bsl
НоваяЗапись.ДокументРеализации = Документы.РеализацияТоваровУслуг.ПустаяСсылка();
НоваяЗапись.Реализовано = Ложь;
```

### Стало

При записи расхода серии документом реализации становится сама отгрузка с хранения, а серия считается реализованной:

```bsl
//++ Панин + Codex 02.07.2026
НоваяЗапись.ДокументРеализации = Источник.Ссылка;
НоваяЗапись.Реализовано = Истина;
//-- Панин + Codex 02.07.2026
```

## Изменение формы документа

В форме документа `ОтгрузкаТоваровСХранения` подключена обработка события `ПередЗаписью`.

Добавлен вызов подготовки служебного реквизита формы:

```bsl
//++ Панин + Codex 02.07.2026
ТТМ_ОбеспечитьРеквизитПодтвержденияОтвязкиСерий();
//-- Панин + Codex 02.07.2026
```

Добавлен блок контроля отвязки серий:

```bsl
//++ Панин + Codex 02.07.2026

Процедура ТТМ_ОбеспечитьРеквизитПодтвержденияОтвязкиСерий()

	ДобавляемыеРеквизиты = Новый Массив;
	ДобавляемыеРеквизиты.Добавить(
		Новый РеквизитФормы(
			"ТТМ_ПодтвержденаОтвязкаСерий",
			Новый ОписаниеТипов("Булево"),
			"",
			"Подтверждена отвязка серий",
			Ложь));

	ИзменитьРеквизиты(ДобавляемыеРеквизиты);

КонецПроцедуры

	КонецЕсли;

	Если ЭтаФорма.ТТМ_ПодтвержденаОтвязкаСерий Тогда
		ЭтаФорма.ТТМ_ПодтвержденаОтвязкаСерий = Ложь;
		Возврат;
	КонецЕсли;

	РежимЗаписи = Неопределено;
	ПараметрыЗаписи.Свойство("РежимЗаписи", РежимЗаписи);

	ОтменаПроведения = РежимЗаписи = РежимЗаписиДокумента.ОтменаПроведения;
	ПометкаНаУдаление = Объект.ПометкаУдаления;
	Если Не ОтменаПроведения
		И Не ПометкаНаУдаление Тогда
		Возврат;
	КонецЕсли;

	Если Объект.Ссылка.Пустая()
		Или Не ТТМ_ЕстьСвязанныеСерийныеНомераОтгрузкиНаСервере(Объект.Ссылка) Тогда

	ТекстВопроса = "Серийные номера будут отвязаны от документа отгрузки."
		+ Символы.ПС
		+ "Повторную отгрузку нужно будет провести из АРМ ""Выпуск и реализация"" заново."
		+ Символы.ПС
		+ "Продолжить?";

	Отказ = Истина;
	Оповещение = Новый ОписаниеОповещения("ТТМ_ПередЗаписьюПослеВопроса", ЭтотОбъект, ПараметрыЗаписи);

		Оповещение,
		ТекстВопроса,
		РежимДиалогаВопрос.ДаНет,

	Если Результат <> КодВозвратаДиалога.Да Тогда
		Возврат;
	КонецЕсли;

	ЭтаФорма.ТТМ_ПодтвержденаОтвязкаСерий = Истина;
	ЭтаФорма.Записать(ПараметрыЗаписи);

КонецПроцедуры

&НаСервереБезКонтекста

		Возврат Ложь;
	КонецЕсли;

	Запрос = Новый Запрос;
	Запрос.Текст = "ВЫБРАТЬ ПЕРВЫЕ 1
	               |	ТТМ_УчетСерийныхНомеровПродукции.Регистратор КАК Регистратор
	               |ИЗ
	               |	РегистрНакопления.ТТМ_УчетСерийныхНомеровПродукции КАК ТТМ_УчетСерийныхНомеровПродукции

//-- Панин + Codex 02.07.2026
```

## Что увидит пользователь

При отмене проведения или пометке на удаление документа, если по нему есть связанные серии, пользователь увидит вопрос:

```text
Серийные номера будут отвязаны от документа отгрузки.
Повторную отгрузку нужно будет провести из АРМ "Выпуск и реализация" заново.
Продолжить?
```

Если пользователь отвечает `Нет`, запись отменяется.

Если пользователь отвечает `Да`, документ записывается повторно, и дальнейшая логика отвязки серий выполняется штатно.

## Объекты конфигурации

Изменены только:

- регистр накопления `ТТМ_УчетСерийныхНомеровПродукции`;
- общий модуль `ТТМ_Подписки`;
- документ `ОтгрузкаТоваровСХранения`;
- форма документа `ОтгрузкаТоваровСХранения`.
