# Выбранные изменения ARM для переноса в прод

Дата: 02.07.2026

Ветка релиза: `release/selected-arm-changes`

## Коротко

В релиз включены изменения по серийному учету для документа `ОтгрузкаТоваровСХранения`.

Цель доработки: чтобы отгрузка товаров с хранения корректно привязывала серийные номера, отмечала их как реализованные, а при отмене проведения или пометке документа на удаление предупреждала пользователя об отвязке серий.

## Что изменено

### 1. Регистр серийных номеров

Файл:

`AccumulationRegisters/ТТМ_УчетСерийныхНомеровПродукции.xml`

В измерение `ДокументРеализации` добавлен новый допустимый тип:

`ДокументСсылка.ОтгрузкаТоваровСХранения`

Раньше в этом поле можно было хранить только ссылку на `РеализацияТоваровУслуг`. Теперь регистр может хранить привязку серии к документу отгрузки с хранения.

XML не размечался комментариями, по договоренности.

### 2. Запись серий при отгрузке с хранения

Файл:

`CommonModules/ТТМ_Подписки/Ext/Module.bsl`

Изменена логика в области `ТТМ_ОтгрузкаТоваровСХранения`.

Что теперь происходит:

- при проведении отгрузки с хранения в расходную запись регистра записывается ссылка на сам документ `ОтгрузкаТоваровСХранения`;
- признак `Реализовано` устанавливается в `Истина`;
- для исходных записей приемки также обновляется `ДокументРеализации`;
- при снятии признака реализации используется пустая ссылка `ОтгрузкаТоваровСХранения`.

В коде эти изменения отмечены комментариями:

```bsl
//++ Панин + Codex 02.07.2026
...
//-- Панин + Codex 02.07.2026
```

### 3. Контроль отвязки серий в форме документа

Файлы:

`Documents/ОтгрузкаТоваровСХранения/Forms/ФормаДокумента/Ext/Form.xml`

`Documents/ОтгрузкаТоваровСХранения/Forms/ФормаДокумента/Ext/Form/Module.bsl`

В форме документа подключено событие `BeforeWrite`, которое вызывает процедуру `ТТМ_ПередЗаписью`.

При отмене проведения или пометке на удаление форма:

- проверяет, есть ли связанные серийные номера по этому документу;
- если связи есть, показывает пользователю предупреждение;
- без подтверждения пользователя запись не продолжается;
- после подтверждения выполняет повторную запись с внутренним флагом `ТТМ_ПодтвержденаОтвязкаСерий`.

Текст предупреждения:

```text
Серийные номера будут отвязаны от документа отгрузки.
Повторную отгрузку нужно будет провести из АРМ "Выпуск и реализация" заново.
Продолжить?
```

BSL-код отмечен комментариями `++ Панин + Codex 02.07.2026` и `-- Панин + Codex 02.07.2026`.

XML формы не размечался комментариями.

## Что не включено в релиз

В релиз сознательно не включены другие отличия тестовой базы от прода:

- новая `ФормаСписка` документа `ОтгрузкаТоваровСХранения` с отладочными сообщениями `ТТМ DEBUG`;
- изменение в `CommonModules/ТТМ_Производство/Ext/Module.bsl`, где убиралась проверка номера клиента `ЗКЗ`;
- раскомментированная доработка формы `ШаблоныЭтикетокИЦенников`;
- служебный `ConfigDumpInfo.xml`.
